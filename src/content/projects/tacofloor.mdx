## About this project

TacoFloor started with the API: objects, schemas, and dependencies defined first. Once the flows were mapped, I built a UI prototype against them. Documentation came last. I've built API reference, and separate user guides for managers and waiters, reflecting the app's permission model. The core idea: one web app for the whole restaurant team, with flows split by role and accountability.
